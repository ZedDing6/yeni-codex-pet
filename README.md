# 夜霓（Yeni）

Codex v2 动画宠物包。

- 图集：`spritesheet.webp`（1536 × 2288，8 × 11，RGBA）
- 配置：`pet.json`
- 体型设定：明确成年御姐轮廓、成熟沙漏曲线与丰满但完整着装的上半身
- 夏装设定：轻薄细肩带上衣、独立高腰短裤
- 腿部设定：明亮自然裸肤直接穿大而疏的黑色菱形渔网袜，无黑丝袜或灰黑透明底层
- 鞋履：黑色露趾踝带高跟凉鞋

## 安装

Windows 最简单的安装方式：解压 ZIP 后双击 `install.cmd`。

它会自动把 `pet.json` 和 `spritesheet.webp` 安装到：

```text
%USERPROFILE%\.codex\pets\yeni\
```

完全退出并重新启动 Codex，然后选择「夜霓」。
